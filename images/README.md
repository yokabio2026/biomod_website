# images フォルダ

サイトで使う画像（写真・図）を入れるフォルダです。

## 画像を追加するときのルール

- **ファイル名は、半角の英数字とハイフンだけ**にします。
  - ○ `team-photo-2026.jpg`　　× `チーム写真.jpg`　　× `team photo.jpg`（スペースも不可）
  - 大文字と小文字は別のファイルとして扱われます。`Photo.JPG` と `photo.jpg` は別物です（ページ側の書き方と完全に同じにしてください）。
- **形式**は `jpg` / `png` / `webp` を使います。写真は jpg、図やロゴは png がおすすめです。
- **大きさ**：横幅 **1600px以内**、ファイルサイズは **500KB以下**を目安にします。
  大きすぎると、ページの表示が遅くなります（アップロード前に縮小してください）。
  文字の多いグラフ・図は、読みやすさを優先して **1MBまで**OKです（横幅1200〜1600px）。
- **個人情報**（顔写真、名前、メールアドレスなど）は、本人の了解を得たものだけを使ってください。

## ページに貼るとき

```html
<img src="images/ファイル名.jpg" alt="画像の説明">
```

`alt` には、画像の内容を短く書きます（画像が表示されないときや、読み上げ時に使われます）。
貼る場所と手順は、README の「⑤ 画像を貼る」を見てください。
