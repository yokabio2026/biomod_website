# videos フォルダ

サイトに直接置く、短い動画（mp4）を入れるフォルダです。

## 動画を追加するときのルール

- **ファイル名は、半角の英数字・ハイフン・アンダースコアだけ**にします。
  - ○ `GUVBinding_1080p.mp4`　　× `実験動画.mp4`　　× `my video.mp4`（スペースも不可）
  - 大文字と小文字は別のファイルとして扱われます。ページ側の書き方と**完全に同じ**にしてください。
- **形式は mp4（H.264）** です。ほとんどのスマホ・パソコンで再生できます。
- **大きさは、1つ25MB以内**にします（これを超えると、アップロードも公開もできません）。
  快適に見せるには、**10MB以下・数十秒まで**が目安です。
- 長い動画・音が大事な動画・大きい動画は、**YouTube（限定公開）** にして、リンクを貼ってください（README の「④」）。
- **個人情報**（顔、名前など）が映る場合は、本人の了解を得たものだけを使ってください。

## ページに貼るとき

GIFのように、**音なしで自動で繰り返し再生**する場合：

```html
<video src="videos/ファイル名.mp4" autoplay loop muted playsinline></video>
```

再生ボタンなどを出して、**普通の動画として見せる**場合：

```html
<video src="videos/ファイル名.mp4" controls></video>
```

貼る場所と手順は、README の「⑥ 動画を貼る」を見てください。
